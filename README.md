# Helix-Ed

Helix-Ed is an online education platform offering personalized STEM and economics instruction for middle and high school students, taught by students from top colleges with a focus on deep conceptual understanding and academic success.

www.helix-ed.org

The `biobrawl` branch contains the BioBrawl website.

## Tech stack

- **Framework:** SvelteKit with TypeScript
- **Styling:** SCSS
- **Content:** Sanity CMS
- **Graphics:** HTML Canvas API
- **Build tooling:** Vite, Vite Imagetools, and Sharp
- **Deployment:** Vercel

Application routes live in `src/routes`, shared components and stores in `src/lib`, global styles in `src/global.scss`, and public assets in `static`.
